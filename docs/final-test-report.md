# Итоговое тестирование клиента

Стенд: `docker compose up -d --build --wait` (client, server, ml, external-systems), данные из сидов бэка. Организации: 1, 2, 3 (ООО), 5, 6 (ИП); организация 4 без владельца. Продукты 1–4 из каталога банка.

## Методика

| Техника | Что проверяли |
| --- | --- |
| Классы эквивалентности и граничные значения | Продукты, которые бэк возвращает для типа организации, суммы (9 999, 10 000, 1 000 000, 1 000 001, 5 000 000, 5 000 001, 10 000 000, 10 000 001, 100 000 000, 100 000 001) и срока (5, 6, 60, 61); эталон считается по каталогу `/external-api/banks/products` |
| Переходы состояний | Черновик → на рассмотрении → скоринг → «Взять» → одобрение, подпись; отказ; другие условия → принять, подпись; другие условия → отказаться. Для каждой организации и каждого доступного ей продукта |
| Негативные переходы | Решение без «Взять», чужим оператором, повторное; подпись до одобрения и после отказа; повторный выбор продукта; ответ на условия без предложения |
| Права доступа | Чужая заявка, список всех заявок, скоринг, «Взять» и решение от имени клиента, запрос без токена, чужая организация |
| Инварианты счётчиков | Число на каждой вкладке очереди равно числу строк при любых сочетаниях «Только мои», поиска и вкладки; плитка «из N в системе» равна «Все» |
| Сквозные сценарии в браузере | ООО: форма подбора, три шага, отправка, решение оператора, подпись и выдача; ИП: продукт с залогом, отказ; другие условия: принять; смена организации; телефон 390 px и экран оператора 1100 px |

## Результат

- Продукты по границам: 70 из 70 совпали с эталоном.
- Жизненный цикл: 165 проверок (20 заявок по 5 организациям и всем 4 продуктам), все прошли после исправления ошибки в самой проверке (принятые условия бэк кладёт в `product`, а не в корень заявки).
- Недопустимые переходы и права доступа: решение без «Взять» и чужим оператором, подпись до одобрения и после отказа, повторный выбор продукта, чужие данные — всё отклоняется.
- Кабинет в браузере: клиент 27 + 12 + 22 проверок, оператор 43, адаптив 10; ошибок в консоли нет, кроме ожидаемого `500` на неверный пароль.
- Найдено на клиенте и исправлено: счётчики вкладок не учитывали «Только мои» и поиск, плитка «из N в системе» считала решённые заявки; подпись платежа на графике округлялась до тысяч (теперь «4,6 тыс ₽»); график на телефоне сжимался до нечитаемого шрифта.
- Найдено на бэке (клиент их обходит, не правит): `docs/backend-requirements.md`, пп. 3.0.10–3.0.17.
