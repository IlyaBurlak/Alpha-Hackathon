_# Alpha Hackathon

Кредитная заявка для малого бизнеса: предприниматель оформляет заявку, ML оценивает её, сотрудник банка принимает решение. Один клиент, два кабинета по роли.

Монорепо: `client` (React + TS), `server` (Express + TS, SQLite), `ml` (FastAPI), `externalSystemsMock` (мок банка, кредитного бюро и реестра).

## Запуск

**Из готового образа** (собирается автоматически из `main` по тегу `vX.Y.Z`, включает клиент, сервер, ML и мок; пакет публичный, вход в ghcr не нужен):

```bash
docker run -d --name alpha -e JWT_SECRET=любая-строка -p 8080:8080 ghcr.io/ilyaburlak/alpha-hackathon:latest
```

Теги: `latest`, `0.0.2`, `0.0`, `sha-<коммит>`. БД (SQLite) лежит внутри контейнера и живёт, пока он не удалён (`docker stop`/`start` её сохраняет, `docker rm` стирает). Постоянный том есть только в варианте «из кода».

**Из кода:**

```bash
cp .env.example .env          # задайте JWT_SECRET
docker compose up -d --build --wait
```

Остановить: `docker compose down` (`-v` удалит и БД).

**Разработка клиента** с hot reload: `cd client && npm install && npm run dev` (сам поднимает бэк, ML и мок в Docker, Vite на :5173). Без Docker: `server` (`npm run dev`, нужен `JWT_SECRET` в `server/.env`) и `ml` (`uvicorn app.main:app --reload`).

## Куда входить

Всё на **http://localhost:8080** (порт задаёт `WEB_PORT`).

| Что | Адрес | Кто |
| --- | --- | --- |
| Кабинет предпринимателя | `/login` → `/cabinet` | пользователи ниже |
| Кабинет сотрудника | `/staff/login` → `/staff` | операторы ниже |
| Панель внешних систем | `/admin` | без входа |

### Панель `/admin`

Открытая страница клиента без авторизации. Переключатели «Сервис доступен / отключён» для банка, кредитного бюро и единого реестра: так в демо показывают, как заявка ведёт себя при недоступной внешней системе. Страница ходит на `/external-api/*`, а nginx проксирует его на мок внешних систем, поэтому ей нужно одно: чтобы мок был запущен (он есть в `docker compose` и в образе `aio`; в `npm run dev` его поднимает сам скрипт). Отдельных переменных окружения для неё нет. Защиты нет, это демо-инструмент: не публикуйте стенд в открытую сеть.

## Переменные окружения

Полный список в `.env.example` и в `.env.example` каждого сервиса.

| Переменная | Что |
| --- | --- |
| `JWT_SECRET` | секрет подписи токенов, обязателен (сервер не стартует без него) |
| `ML_SERVICE_URL` | адрес ML, в compose `http://ml:8000` |
| `WEB_PORT` | порт на хосте, по умолчанию 8080 |

## CI и релиз

`.github/workflows/ci.yml` на пуши и PR в `develop` и `main`: проверки сервисов, интеграционные тесты бэка (если менялся `server/`), сборка образа `aio/Dockerfile` и smoke-тест. Ветки: `develop` — разработка, `main` — релизы. Образ в ghcr публикуется только по тегу `vX.Y.Z` на коммите из `main`:

```bash
git checkout main && git tag v0.0.3 && git push origin v0.0.3
```

Отчёт интеграционных тестов (Allure) — https://ilyaburlak.github.io/Alpha-Hackathon/ (обновляется после пуша в `develop` или `main`).
